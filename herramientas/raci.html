• Matriz RACI

Quién hace, quién responde, a quién se consulta y a quién se informa en cada actividad.

RResponsable ejecuta la tarea AAprobador rinde cuentas, decide (uno solo) CConsultado opina antes (doble vía) IInformado se entera después (una vía) A/Rmismo rol ejecuta y aprueba
Cómo completarlo
  • Columnas = roles o personas; filas = actividades o entregables. Escribí directo en los encabezados y en las tareas.
  • Cada celda: clic para rotar entre R → A → A/R → C → I → vacío. Con el teclado: R, A, C, I y Supr para borrar.
  • Regla de oro: cada actividad lleva una sola A y al menos una R. La columna “Control” te avisa si falta algo.
  • Cuidado con las C: cada consulta suma demora. Si todos son C, nadie decide.
  • La fila “Carga (R)” muestra cuántas actividades ejecuta cada rol: sirve para detectar sobrecarga.
